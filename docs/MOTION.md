# Моушн-графика (`motion:`) и иллюстрированные ролики

Основной способ делать графику для роликов. Он заменяет ручную расстановку фигур (`draw:`): вместо координат каждой плашки сцена описывается **списком блоков** (заголовок, карточка-пословица, счётчик, столбцы, шкала, комментарий…), а вёрстку, размеры шрифта, отступы и анимацию делает движок.

- Движок — [Remotion](https://www.remotion.dev) (React + CSS), лежит в [`engine/motion/`](../engine/motion). Рисует кадры по времени, как и раньше, а голос, тайминг слов, субтитры, звук, эффекты и сведение остаются нашими.
- **Персонажи и сцены** — ИИ-иллюстрации (плиты `plates/`) в одном стиле, оживлённые 2.5D-параллаксом и эффектами. Графика `motion:` накладывается поверх них прозрачным слоем.
- **Инфографика** (цифры, сравнения, правила, призыв) — полнокадровые `motion:`-сцены на фирменном фоне.

Пример ролика целиком: [`projects/proverbs/project.yaml`](../projects/proverbs/project.yaml) («Пословицы-тормоза»).

## 1. Почему так

| Было (`draw:`) | Стало (`motion:` + иллюстрации) |
|---|---|
| Каждый элемент ставится числами `x/y`, отсюда «почти по центру», наезды и уезды | Блоки стоят в колонке (flexbox): центр, отступы и ритм одинаковые всегда |
| Шрифт подбирается вручную, длинный текст уходит за край | Заголовок сам подбирает размер и делит строки поровну; колонка, которая не влезает, уменьшается целиком |
| Человечки из кружков и палочек | Персонажи с ИИ-иллюстраций в едином стиле |
| Линейные сдвиги, «деревянное» движение | Пружинная физика (`spring`): элементы прилетают с весом и оседают |
| Каждая сцена рисуется с нуля | Готовые блоки с единой дизайн-системой: палитры, шрифты, шкала размеров |

Старый `draw:` продолжает работать (школа, казино, галерея), но для новых роликов используйте `motion:`.

## 2. Быстрый старт

```yaml
motion: {palette: night}                 # значения по умолчанию для всех motion-шотов проекта

scenes:
  - id: hook
    text: "Три пословицы из детства тихо держат тебя на месте."
    shots:
      - id: h_art                          # иллюстрация + графика поверх
        plate: hook                        # projects/<id>/plates/hook.png
        camera: {keys: [{t: 0, z: 1.0}, {t: end, z: 1.1}], parallax: {px: 10, k: [0, 0.05]}}
        motion:
          scrim: {side: top, k: 0.75, h: 34}     # затемнение под текстом
          align: top
          blocks:
            - {type: title, text: "3 пословицы, которые **тормозят**", at: 0.2}
      - id: h_count                        # полнокадровая графика
        start: "@сто-0.15"
        motion:
          backdrop: {pattern: folk}
          blocks:
            - {type: proverb, text: "Семь раз отмерь — один раз отрежь", at: 0.05}
            - {type: number, value: 100, from: 1, prefix: "×", at: "@сто"}
```

```bash
python3 vg.py compile <id>
python3 vg.py motion <id> --frames 30,140     # отдельные кадры графики (быстро)
python3 vg.py preview <id> --shots            # кадр из середины каждого шота: графика + сцена + субтитры
python3 vg.py all <id>                        # полный ролик (motion-шоты рендерятся сами)
```

Время везде — `"@слово"` (как в остальном проекте) или **число секунд от начала шота**.

## 3. Шот с `motion:`

| Ключ | Что делает |
|---|---|
| `palette` | палитра: `night` (ночная синь, золото), `ember` (тёплая), `dusk` (фиолетовая), `forest` (зелёная), `paper` (светлая) |
| `colors` | замена отдельных цветов палитры: `{accent: "#ffd34d", pos: "#b6ff3b"}` |
| `backdrop` | фон полнокадровой сцены: `pattern: none / folk / grid / dots / rays`, `glow` (0–1.5), `light: [x%, y%]` |
| `scrim` | только поверх иллюстрации: затемнение под текстом `{side: top / bottom / both, k: 0.7, h: 40}`; `false` — без него |
| `align` | где колонка блоков на сцене: `center` (по умолчанию), `top`, `bottom`, `between` |
| `stage` | границы сцены `{top: 230, bottom: 1170}`; ниже — пояс субтитров |
| `gap` | расстояние между блоками (40) |
| `camera` | `{zoom: [1, 1.035], y: [0, -14], shakes: [{at, amp, dur}]}` — медленный наезд всегда, тряска на ударах |
| `blocks` | колонка блоков (§4) |
| `layers` | свободные элементы поверх: любой блок с `x, y` и `keys: [{at, x, y, rot, scale, opacity}]` (пружинные переходы) |
| `particles` | частицы: `{kind: sparks / confetti / dust, at, region: [x0, y0, x1, y1], count, size, colors, speed}` |

Если у шота есть `plate:`, графика рендерится с прозрачным фоном и накладывается на иллюстрацию **после** цветокоррекции (текст остаётся чётким). Без `plate:` — полнокадровая сцена с фоном палитры.

## 4. Блоки

Общие ключи любого блока: `at` (появление), `until` (уход), `enter` (`rise`, `pop`, `drop`, `stamp`, `left`, `right`, `zoom`, `wipe`, `blur`, `fade`, `none`), `exit` (`fade`, `shrink`, `up`, `left`), `float` (парение: число или `{amp, freq, rot}`), `pos: {y}` (вне колонки, по центру на высоте `y`). До момента `at` блок невидим, но **место под него уже занято**, поэтому ничего не прыгает.

Разметка текста: `**слово**` — акцентный цвет палитры, `[слово](pos)` — цвет по имени (`pos`, `neg`, `accent`, `muted` или `#hex`).

| Блок | Что это | Ключи |
|---|---|---|
| `kicker` | метка-таблетка над заголовком | `text`, `icon` (имя иконки [Lucide](https://lucide.dev/icons): `Ear`, `Brain`, `Lightbulb`…), `color` |
| `title` | крупный заголовок, слова появляются по одному | `text`, `size` (`hero xl l m s` или px), `lines` (не больше N строк, по умолчанию 3), `sync: true` (каждое слово — ровно когда его произносит диктор), `stagger`, `upper`, `font` (`display body folk`), `enter: rise / pop` |
| `text` | абзац | `text`, `size` (`lead body label small`), `color`, `width` |
| `number` | большая цифра со счётчиком | `value`, `from`, `prefix`, `suffix`, `decimals`, `dur`, `label`, `color`, `size` (px) |
| `proverb` | бумажная карточка с народным орнаментом | `text`, `size`, `rot`, `strike` (зачеркнуть), `crack` (трещина), `break` (раскол: половинки падают), `dim` |
| `versus` | две карточки и «VS» между ними | `a: {text, icon, color, at}`, `b: {...}`, `vs_at`, `kind: proverb / card` |
| `bars` | горизонтальные столбцы-сравнения | `items: [{label, value, color, at, note}]`, `values` (подписи значений), `unit`, `max` |
| `meter` | шкала с отметкой | `label`, `value`, `at`, `dur`, `mark` (значение отметки), `mark_label`, `mark_at`, `color` |
| `checklist` | список с галочками | `items: [{text, at, no: true}]`, `color` |
| `badge` | плашка | `text`, `icon`, `color`, `style: solid / outline` |
| `stamp` | штамп-вердикт | `text`, `color`, `rot`, `size` |
| `card` | карточка с иконкой | `title`, `text`, `icon`, `color` |
| `comment` | комментарий в соцсети, печатается по буквам | `name`, `text`, `at`, `cps` (букв в секунду), `placeholder`, `likes`, `like_at` |
| `icon` | иконка в круге | `name`, `size`, `color` |
| `sprite` | картинка из папки проекта | `src` (`plates/x.png` или `art/x.png`), `h` |
| `source` | мелкая строка источника | `text` |
| `spacer` | отступ | `h` |
| `swap` | несколько блоков в одной ячейке: следующий сменяет предыдущий без сдвига вёрстки | `items: [...]` (у каждого `at` / `until`) |
| `row` | блоки в строку | `items: [...]`, `gap` |

## 5. Дизайн-система

Все значения — в [`engine/motion/src/theme.ts`](../engine/motion/src/theme.ts), одни на все ролики:

- **Шрифты:** Unbounded (заголовки, цифры, штампы), Manrope (текст, подписи), Kurale (пословицы, цитаты — «старинный» шрифт с кириллицей), JetBrains Mono (метки, источники). Все поставляются пакетами `@fontsource`, работают офлайн, рендер ждёт их загрузки.
- **Шкала размеров:** `hero 132 · xl 112 · l 92 · m 74 · s 58` для заголовков; `lead 50 · body 42 · label 36 · small 30` для текста; цифры — 230.
- **Сетка:** поля по 72 px; сцена — y 230–1170; ниже — субтитры (≈1250); правая колонка и низ ниже 1570 — для интерфейса площадки.
- **Цвета палитры:** `accent` (единственный акцент), `pos` (можно, лучше), `neg` (нельзя, хуже, риск), `ink`, `muted`, `card` / `cardInk` (бумага), `folk` (орнамент).
- **Движение:** пружины `pop` (с лёгким перелётом), `snappy` (интерфейс, слова), `smooth` (столбцы, шкалы, камера), `heavy` (падения, штампы).

Правила вёрстки, которые движок держит сам: всё по центру на оси x = 540; заголовок не выходит за поля и не висит одним словом; одинаковые блоки одинаковые; блок резервирует место заранее; колонка, которая не влезает, уменьшается целиком.

## 6. Иллюстрации: персонажи и сцены

1. **Библия стиля** — одна фраза стиля для всех кадров ролика (запишите её комментарием в `project.yaml`). Пример: `Style: premium editorial flat illustration, bold simple shapes, subtle grain texture, soft gradients, limited palette of deep indigo, cream, amber and folk red, like a modern animated explainer film. No text, no letters, no UI, no watermark.`
2. **Композиция под титры:** «subject in the lower two thirds, the top third is empty calm background for titles». Сквозного героя описывайте одинаковыми словами («a young man in a blue t-shirt and dark jeans»).
3. **Генерация:** Figma AI (`generate_image`, модель `gemini-3.1-flash-image`, 1152×2048) → скачать `image.url` в `projects/<id>/plates/<имя>.png`. Каждый вызов тратит кредиты Figma AI: делайте ровно столько кадров, сколько нужно (обычно 4–7 на минуту), сообщайте число.
4. Посмотрите все кадры вместе (контактный лист): один стиль, нет мусорного текста, руки и лица в порядке.
5. `python3 vg.py prep <id>` — апскейл и карта глубины (2.5D-параллакс), затем камера и эффекты шота как в `docs/MANUAL.md` (§9).

Ритм ролика: иллюстрация (персонаж, ситуация) → графика (факт, цифра, сравнение) → иллюстрация… Смена каждые 2–5 с, графика поверх иллюстрации — только в верхней трети (`align: top`, `scrim`).

## 7. Проверка качества

- `python3 vg.py motion <id> --frames …` и `preview --at …` — смотреть кадры в момент появления каждого блока и в конце шота.
- Текст поверх иллюстрации — только на затемнении (`scrim`), не на лицах.
- На кадре один главный акцент и не больше трёх текстовых блоков.
- Цифры в кадре совпадают с источниками сценария, источник подписан блоком `source`.
- `python3 vg.py storyboard <id>` → публикация раскадровки на согласование перед полным рендером.

## 8. Разработка движка

```bash
cd engine/motion
npm ci                       # (делает setup.sh)
npx tsc -p .                 # проверка типов
VG_CHROME=/opt/pw-browsers/chromium_headless_shell-*/chrome-headless-shell-linux64/chrome-headless-shell npm run studio   # Remotion Studio
```

- Новый блок: компонент в `src/blocks/*.tsx` (время — `useT()`, пружина — `sp(t, at, fps, 'pop')`, цвета — `useCtx().pal`), строка в `BLOCKS` в `src/Shot.tsx`, строка в таблице §4.
- Анимации — только через время кадра (`useT`, `sp`, `ramp`, `interpolate`); CSS-transition и animation в покадровом рендере не работают.
- Рендер: [`engine/motion/render.mjs`](../engine/motion/render.mjs) — сборка webpack один раз на версию кода, неизменённые шоты пропускаются.
- Лицензия Remotion: бесплатно для частных лиц и команд до 3 человек; компании от 4 человек покупают лицензию ([remotion.dev/license](https://www.remotion.dev/docs/license)).

## 9. Проблемы и решения

| Симптом | Решение |
|---|---|
| `engine/motion/node_modules is missing` | `./setup.sh` или `cd engine/motion && npm ci` |
| `motion: unknown block type` | опечатка в `type`; список — §4 |
| `motion frame N of shot S is missing` | `python3 vg.py motion <id>` (или `scene` — он вызывает рендер сам) |
| иконка не появилась | имя из [lucide.dev/icons](https://lucide.dev/icons) в стиле PascalCase: `MessageCircle`, `TrendingDown` |
| текст мелкий | значит, колонка не влезла и уменьшилась: уберите блок или разделите шот на два |
