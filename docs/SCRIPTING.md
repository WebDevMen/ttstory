# Сценарии: от темы до готового сценария на 60 секунд

Инструмент сценариев превращает тему («что будет, если в доме на 3 дня отключат свет») в полный сценарий ролика для TikTok, Reels и Shorts: исследование с источниками, выбор угла подачи, лаборатория крючков, текст диктора по секундам, раскадровка (что в кадре, какие актёры, камера, анимация, графика, звуки, переходы — и на каком слове), карта удержания, вовлечение, упаковка для каждой площадки и честная самопроверка. Сценарий хранится в `projects/<id>/script.yaml`, проверяется автоматически и превращается в документ `script.md` и в черновик `project.yaml` для производства видео.

Эталон: [`projects/blackout/script.yaml`](../projects/blackout/script.yaml) → [`script.md`](../projects/blackout/script.md).

## 1. Быстрый старт

```bash
python3 vg.py script formats                         # форматы, типы крючков, роли, приёмы, звуки
python3 vg.py script formats what_if                 # структура одного формата
python3 vg.py script new blackout --topic "Что будет, если в доме на 3 дня отключат свет" \
        --format what_if --duration 60 [--platforms tiktok,reels,shorts] [--wishes "без запугивания"]
#   → projects/blackout/script.yaml: блоки формата с бюджетом секунд и слов, каждое поле TODO
python3 vg.py script check blackout                  # тайминг, все замечания, оценка 0–100
python3 vg.py script check blackout --tts            # то же по реальной озвучке (точные секунды слов)
python3 vg.py script render blackout                 # документ projects/blackout/script.md
python3 vg.py script project blackout                # черновик projects/blackout/project.yaml для видео
```

Через Claude Code достаточно написать: «Напиши сценарий на тему …» (или `/write-script`). Claude пройдёт процесс по [`.claude/skills/write-script/SKILL.md`](../.claude/skills/write-script/SKILL.md): исследует тему в интернете, выберет угол и формат, напишет и проверит сценарий и пришлёт документ.

## 2. Процесс: 10 шагов

| # | Шаг | Результат в `script.yaml` |
|---|---|---|
| 1 | **Бриф.** Тема, пожелания, площадки, длительность. Кто зритель, чего он боится и хочет, что уже знает. Что он получит, досмотрев (обещание). | `meta`, `brief` |
| 2 | **Исследование.** 5–8 проверенных фактов с источниками (официальные сайты, исследования, крупные СМИ). Что в теме удивляет, что спорно, какие вопросы задают. | `research.facts`, `research.summary`, `research.insights` |
| 3 | **Углы подачи.** 3–4 разных способа рассказать тему, оценка 1–10 и почему. Выбрать один. | `research.angles`, `chosen_angle` |
| 4 | **Формат.** Структура, которая лучше всего несёт этот угол (раздел 5). | `meta.format`, `beats` |
| 5 | **Крючки.** 8+ вариантов 4+ типов, оценить каждый, выбрать основной и 2 запасных для A/B. | `hooks` |
| 6 | **Текст.** Блок за блоком, по бюджету слов из шаблона, по правилам раздела 7. | `beats[].vo`, `on_screen` |
| 7 | **Раскадровка.** Кадры каждого блока: что в кадре, актёры, камера, анимация, графика, звук, переход — каждое событие на слове. | `beats[].shots` |
| 8 | **Удержание и вовлечение.** Петли, приёмы, награды каждые 10–15 с, повод для комментария, пересылки, сохранения, призыв. | `loops`, `devices`, `engagement` |
| 9 | **Упаковка.** Подпись, хэштеги, обложка, заголовок Shorts, первый кадр. | `package` |
| 10 | **Проверка и самооценка.** `script check` (и `--tts`) до 0 ошибок и ≤ 3 предупреждений, честные оценки 1–10, слабые места. Затем `script render`. | `review`, `script.md` |

## 3. Что важно площадкам

Разделяем **официальное** (сказала сама площадка) и **практику** (широко известно у авторов, но не подтверждено). Источники и лимиты — в [`engine/script/data/platforms.yaml`](../engine/script/data/platforms.yaml); их использует проверка.

**TikTok**
- Официально: рекомендации строятся на взаимодействиях (лайки, репосты, подписки, комментарии), информации о видео (подпись, звук, хэштеги) и слабее — на настройках устройства. Сильный сигнал интереса — досмотр длинного видео до конца. Число подписчиков не является прямым фактором. ([TikTok Newsroom](https://newsroom.tiktok.com/en-us/how-tiktok-recommends-videos-for-you))
- Практика: решают время просмотра, досматриваемость, пересмотры, затем репосты и сохранения. Поиск читает речь, текст на экране и подпись — одно ключевое слово во всех трёх местах. В ленте видна первая строка подписи (~100 символов). Для Creator Rewards нужны ролики длиннее минуты.

**Instagram Reels**
- Официально (Адам Моссери, январь 2025): главные сигналы — время просмотра, отправки на охват (sends per reach), лайки на охват. С декабря 2025 — не больше 5 хэштегов.
- Практика: пересылки в директ особенно важны для новых зрителей — ролик должен быть «для кого-то». Обложка решает клики из профиля.

**YouTube Shorts**
- Официально: до 3 минут; с 31 марта 2025 просмотр считается при каждом запуске/повторе (прежняя метрика — «вовлечённые просмотры»); в аналитике есть «Смотрели / пролистнули» — прямой показатель крючка.
- Практика: пересмотры повышают счётчик — зацикленный финал полезен; заголовок короткий, с ключевым словом.

**Общее:** многие смотрят без звука — первые секунды должны читаться из картинки и текста; безопасные зоны: верх ~150 px, низ от ~1550 px, правая колонка x > 940 на высоте 800–1550; площадки продвигают оригинальный контент.

Что из этого следует для сценария: **досмотр и пересмотр** (крючок, награды, петли, финал-петля), **пересылки и сохранения** (польза «для кого-то», чек-лист), **комментарии** (вопрос с ответом одним словом), **поиск** (ключевое слово в речи, на экране и в подписи).

## 4. Крючок: первые 3 секунды

Правила (проверяются автоматически):
- первая фраза заканчивается до ~3 секунд (8–12 слов); никаких «привет», «сегодня мы», «в этом видео»;
- первый кадр живой и понятен без звука: в первые 1.5 с — минимум два визуальных события;
- ключевое слово темы — в первой фразе;
- конкретика: «3 дня без света», а не «долгое отключение»; обращение на «ты»;
- обещание крючка обязательно выполняется в ролике.

12 типов крючков (`python3 vg.py script formats` печатает формулы и примеры): `imagine` «Представь…», `pov`, `stakes` (время/ресурс и угроза), `question`, `shock_fact`, `contrarian`, `curiosity_gap` («скажу в конце»), `list_promise`, `challenge`, `callout` («если ты живёшь в…»), `result_first`, `visual_shock`. На каждый сценарий — минимум 8 вариантов 4 типов с оценкой по критериям: останавливает, понятно, обещает, конкретно, касается зрителя, сильный первый кадр. Основной крючок (`hooks.primary`) — начало первого блока; два запасных (`hooks.ab`) — для A/B-теста.

## 5. Форматы и роли блоков

| Формат | Когда | Структура |
|---|---|---|
| `what_if` Что будет, если… | гипотетика, выживание, наука | крючок → завязка → эскалация ×2 → поворот → развязка → призыв |
| `survival_guide` Мануал | инструкции в стрессе | крючок → ставки → шаг ×2 → ошибка → шаг → сводка → призыв |
| `myth_busting` Миф или правда | заблуждения | крючок → контекст → доказательство → раскрытие → развязка → призыв |
| `listicle` Топ-N | подборки | крючок → пункт ×3 → сводка → призыв |
| `explainer` Почему так? | наука, техника | крючок → контекст → доказательство → раскрытие → развязка → призыв |
| `story` История | кейсы, драма | крючок → контекст → проблема → эскалация → поворот → развязка → призыв |
| `fiction` Вымысел | мистика, фантастика, фэнтези, серии (§14) | крючок → завязка → беда → эскалация → правило мира → поворот → обрыв → призыв |
| `day_in_life` Один день | культура, профессии | крючок → пункт ×3 → раскрытие → пункт → призыв |
| `comparison` X против Y | сравнения | крючок → пункт ×2 → поворот → развязка → призыв |
| `how_to` Как сделать | обучение, рецепты | крючок → шаг ×2 → ошибка → шаг → развязка → призыв |
| `mistakes` N ошибок | быт, здоровье, деньги | крючок → ошибка ×3 → сводка → призыв |
| `quiz` Проверь себя | интерактив | крючок → пункт ×3 → раскрытие → призыв |
| `timeline` Как менялось | история | крючок → пункт ×2 → поворот → развязка → призыв |

Подробно (доли времени, цель каждого блока, подходящие крючки и визуал): `python3 vg.py script formats <имя>`, файл [`engine/script/data/formats.yaml`](../engine/script/data/formats.yaml). Структура — отправная точка: блоки можно делить, добавлять и переставлять, но обязательные роли формата должны остаться.

**Роли блоков:** `hook`, `context`, `setup`, `stakes`★, `problem`★, `point`★, `step`★, `mistake`★, `escalation`★, `twist`★, `proof`★, `reveal`★, `payoff`★, `recap`★, `rule`★ (правило вымышленного мира), `cliffhanger`★ (обрыв), `cta`, `loop`. ★ — «награда»: зритель получает новый факт, шаг или ответ.

## 6. Удержание: награды, петли, приёмы

- **Награда каждые 10–15 с.** Между блоками-наградами не больше ~18 с. Во второй половине обязательно развязка, раскрытие, поворот или сводка — то, ради чего досматривают.
- **Открытая петля в первые 8 с.** Вопрос или обещание, ответ на которое будет позже (`loops: [{id, question, open, close}]`). Петель может быть несколько, вложенных: одну можно закрыть раньше, но хотя бы одна должна держать интригу после середины ролика.
- **Визуальное событие каждые 2–3 с.** Смена кадра, появление графики, движение, звук. Пауза больше 3.5 с — замечание, меньше 3 событий на 10 с — замечание.
- **Приёмы** (`beats[].devices`, нужно ≥ 5 разных): `open_loop`, `pattern_interrupt`, `stakes_raise`, `progress`, `direct_address`, `visual_proof`, `mini_payoff`, `number_reveal`, `contrast`, `twist`, `sound_hit`, `text_reinforcement`, `callback`, `relatability`, `emotion`; для вовлечения — `comment_bait`, `share_trigger`, `save_trigger`, `follow_trigger`, `rewatch_trigger`, `loop_ending`. Что это и как сделать движком — [`engine/script/data/devices.yaml`](../engine/script/data/devices.yaml).
- **Музыка ведёт эмоцию:** у каждого блока `music` (drone, pulse, tension, dark, sub, epic, calm, lofi, upbeat, silence); смена стиля на повороте и развязке.

## 7. Текст для диктора

- **Темп:** при `rate +18…+20%` — 2.2–2.8 слова в секунду; 60 секунд ≈ 140–150 слов. Шаблон даёт бюджет слов каждому блоку; проверка предупреждает при темпе выше 3.4 слова/с.
- **Предложения ≤ 14 слов.** Одна мысль — одно предложение. Тире `—` и точка дают паузу.
- **Числа словами** в нужном падеже («через четыре часа», «выше девятого этажа») — синтезатор ошибается в склонениях цифр. На экране цифры можно (`on_screen: "4 ЧАСА"`).
- **Без латиницы и аббревиатур** в голосе: «вайфай», «пауэрбанк»; аббревиатуры — раскрыть или проверить произношение. Пишите `ё`, где важно ударение.
- **Каждая цифра — из исследования:** блок-награда с числом ссылается на факты (`facts: [f1]`); факт с `confidence: low` — перепроверить или смягчить.
- **«Ты», а не «мы рассмотрим».** Конкретные предметы и ситуации из жизни зрителя.

Длительность считается до озвучки моделью, подобранной по реальным проектам репозитория: `речь = 0.132 с × слоги / (1 + темп) + 0.795 с × точки + 0.259 с × запятые/тире` (ошибка ~0.24 с на блок, ~1% на ролик), плюс паузы движка между сценами и финальный кадр. `--tts` озвучивает каждый блок настоящим голосом (кэшируется) и даёт точные секунды каждого слова.

## 8. Визуальная режиссура

Каждый блок — 1–4 кадра (`shots`). Каждый кадр:

| Поле | Что писать |
|---|---|
| `id` | латиница, уникально во всём сценарии (станет id шота в проекте) |
| `at` | момент смены кадра (кроме первого): `"@слово-0.1"` — чуть раньше ключевого слова |
| `visual` | что в кадре: объект, действие, планы (передний / средний / фон), цвет, свет |
| `actors` | из чего рисуется: актёры движка (`python3 vg.py actors`), `hud:<компонент>`, `new:<имя>` — актёр, которого надо написать |
| `camera` | движение: наезд, отъезд, панорама, подъём, тряска на ударе |
| `animation` | `[{at, what}]` — что двигается и на каком слове |
| `graphics` | `[{at, type, text}]` — надписи, плашки, цифры, выноски (≤ 7 слов) |
| `sfx` | `[{at, sound, note}]` — звук из движка (`script formats` → ЗВУКИ) или `new:<имя>` |
| `ambience` | фон кадра: `city`, `wind`, `rain`, `room`… |
| `effects` | эффекты сцены (частицы, свечение, туман) — словами или списком |
| `transition` | `cut whip_x whip_y zoom slam glitch dip flash fade dissolve` |

**Время везде — ссылки на слова текста этого блока:** `"@слово"`, `"@слово#2"` (второе вхождение), `"@слово.end"`, `"@слово+0.3"`, `"@start"`/`"@end"` блока, `"@другой_блок/слово"`, число — секунды от начала блока. Проверка находит каждое слово, считает абсолютное время, ругается на несуществующие слова, на события вне своего кадра и на кадры короче 0.6 с.

Правила картинки: первый кадр живой с первой секунды; ни одного статичного кадра дольше 3 с; каждое утверждение подтверждено картинкой (цифра растёт, предмет появляется); каждое визуальное событие — со звуком; цвет ведёт эскалацию; крупный текст дублирует ключевую фразу для смотрящих без звука; финальный кадр перекликается с первым.

## 9. Вовлечение и призыв

- `comment` — конкретный вопрос или выбор с ответом одним словом/числом («А ты на каком этаже?»), а не «пишите мнение».
- `share` — кому и зачем перешлют; `save` — почему вернутся (чек-лист, сводка); `follow` — серия или рубрика; `rewatch` — детали, быстрые цифры, финал-петля.
- `cta` — одна главная просьба (максимум две, связанные с темой) в последних 25–30% ролика: `{beat, text, type: comment | save | share | follow | part2}`.

## 10. Упаковка: подпись, хэштеги, обложка

| Площадка | Поля | Лимиты (проверяются) |
|---|---|---|
| `tiktok` | `caption`, `hashtags`, `cover`, `sound` | подпись ≤ 2200 символов, ключевое слово в первых 100; 3–5 хэштегов |
| `reels` | `caption`, `hashtags`, `cover` | ≤ 2200 символов; 1–5 хэштегов, больше 5 нельзя |
| `shorts` | `title`, `description`, `hashtags` | заголовок ≤ 100 символов; 1–3 хэштега |

`cover` — текст обложки ≤ 6 слов; `first_frame` — каким будет первый кадр (он же превью в ленте); `posting` — время публикации и закреп.

## 11. Справочник script.yaml

```yaml
version: 1
meta:       {title, topic, wishes, language: ru, platforms: [tiktok, reels, shorts], primary_platform,
             duration: 60, format: what_if, style: draw | motion | plates | mixed,   # draw — по умолчанию; как выбрать — MANUAL.md §0
             genre: nonfiction | fiction,                                         # fiction — вымысел, §14
             voice: {voice: ru-RU-DmitryNeural, rate: "+18%", pitch: "+0Hz"}, status: draft | checked | approved}
brief:      {goal, kpi: [completion rewatch shares saves comments follows likes clicks monetization],
             audience: {who, age, interests: [], pains: [], desires: [], knowledge},
             promise, tone, keywords: [главное слово, …], constraints: []}
research:   {summary, facts: [{id, text, source: URL, confidence: high | medium | low}],
             angles: [{id, text, score: 1–10, why, archetype, paradox}], chosen_angle, insights: []}
story:      {premise, paradox, genre,                                             # только для вымысла, §14
             world_rules: [{id, rule, shown_in: <блок>, basis: <fN | вымысел>}],
             characters: [{id, name, role, want, fear, look, arc}],
             twists: [{id, what, setup: <блок>, payoff: <блок>}],
             stakes: [{beat, level: personal | family | community | world}],
             series: {name, part, of, prev, next, answers, cliff}}
hooks:      {variants: [{id, type, vo, on_screen, visual, score, why}], primary, ab: [id, id]}
beats:
  - id: hook                 # латиница; станет id сцены
    role: hook               # раздел 5
    title, goal              # заголовок и задача блока
    vo: "Текст диктора."
    on_screen: "2–5 СЛОВ"    # крупный текст
    devices: [open_loop, …]  # раздел 6
    facts: [f1]              # на каких фактах стоит блок
    music: drone
    marks: {"три дня": "#ff3b4e"}   # подсветка слов в субтитрах (необязательно)
    accent: "#ff3b4e"        # цвет сцены (необязательно)
    gap_after: 0.42          # пауза после блока, с (необязательно)
    shots: [{id, at, visual, actors, camera, animation, graphics, sfx, ambience, effects, transition}]
loops:      [{id, question, open: <блок>, close: <блок>}]
engagement: {comment, share, save, follow, rewatch, cta: {beat, text, type}}
package:    {tiktok: {caption, hashtags, cover, sound}, reels: {caption, hashtags, cover},
             shorts: {title, description, hashtags}, first_frame, posting}
production: {theme: {preset, accent, captions}, palette: [], music: {key, mode, bpm}, assets: [], notes: []}
review:     {scores: {hook, clarity, pacing, novelty, emotion, payoff, visuals, cta, platform, accuracy},
             weak_points: [], improvements: []}
```

Строки с `: ` внутри и списки с запятыми внутри пунктов берите в кавычки: `desires: ["понять, что будет", "…"]`.

## 12. Проверка и оценка готовности

`python3 vg.py script check <id>` печатает тайминг блоков (начало–конец, секунды речи, слова, темп), все замечания по группам и метрики. **Оценка = 100 − 12 × ошибки − 3 × предупреждения.** Сценарий **готов к производству**, когда ошибок 0 и предупреждений не больше 3 (код выхода 0). Незаполненное `TODO` — ошибка; пока текст диктора заполнен не во всех блоках, проверки времени пропускаются.

| Группа | Ошибка ✗ | Предупреждение ! |
|---|---|---|
| Схема | нет обязательных полей, неизвестные формат/роль/тип крючка/приём/площадка/переход/музыка, повтор id, ссылки на несуществующие факты, крючки, блоки | неизвестный KPI |
| Длительность | вне ±30% от цели | вне ±12% от цели; монетизация TikTok и ролик ≤ 60 с |
| Крючок | первый блок не `hook`; первая фраза дольше 4.5 с; приветствие в начале; не выбран основной крючок | фраза дольше 3.2 с; < 8 вариантов или < 4 типов; первый блок не начинается с основного; < 2 запасных; нет текста на экране; ключевого слова нет в первой фразе |
| Текст | — | темп > 3.4 слова/с; предложение > 14 слов; цифры, латиница, аббревиатуры в голосе; число в блоке-награде без факта; факт низкой уверенности; текст на экране > 7 слов |
| Кадры | слово в `at` не найдено; кадр начинается не позже предыдущего; неизвестный актёр, HUD-компонент, звук, фон | событие вне своего кадра; кадр < 0.6 с; draw-кадр без актёров; надпись > 7 слов; блок > 14 с меньше чем из 4 кадров |
| Ритм | нет ни одного визуального события | < 2 событий в первые 1.5 с; пауза > 3.5 с; < 3 событий на 10 с |
| Структура и удержание | нет обязательной роли формата; нет блоков-наград; нет развязки/раскрытия/поворота/сводки после 45%; петля закрывается раньше, чем открывается | > 18 с без награды; все петли закрываются в первой половине; нет петли в первые 8 с; < 5 приёмов; нет музыки |
| Вовлечение | нет повода для комментария; нет призыва | комментарий не вопрос/выбор; нет поводов share/save/rewatch/follow; призыв раньше 70%; > 2 просьб; финал не призыв/петля/развязка |
| Исследование | факт без источника | < 4 фактов с источниками; источник без ссылки; ни один факт не использован; < 3 углов; не выбран угол |
| Упаковка и SEO | подпись или хэштеги сверх лимита площадки; заголовок Shorts > 100 | нет упаковки площадки; ключевое слово не в первых 100 символах подписи TikTok; хэштегов вне рекомендации; обложка > 6 слов; нет первого кадра; нет ключевых слов; ключевое слово ни разу не на экране |
| Самопроверка | оценки не проставлены | нет оценки по аспекту; оценка < 7 |

Заметки (·) не снижают оценку: новые актёры и звуки, которые придётся сделать, один стиль музыки на весь ролик.

`python3 vg.py script render <id> [--tts]` собирает документ `script.md`: паспорт с готовностью, бриф, исследование с источниками, таблицу крючков, сценарий по секундам (голос, текст на экране, кадры, анимация, графика, звук с абсолютным временем), карту удержания с полосой плотности событий, вовлечение, упаковку, продакшн, самопроверку с замечаниями и чистый текст диктора.

## 13. Передача в производство

```bash
python3 vg.py script project <id>          # projects/<id>/project.yaml (не перезапишет существующий без --force)
python3 vg.py voice <id> && python3 vg.py compile <id>
```

Черновик проекта уже содержит голос, тему, сцены с текстом, кадры со сменой на словах и переходами, музыкальные секции по блокам, звуки и фоны на словах, подсветку слов в субтитрах. Вместо картинки каждый кадр — аниматик-карточка (текст на экране, описание кадра, надписи по времени), поэтому темп можно проверить сразу (`preview`). План каждого кадра (визуал, актёры, камера, анимация) записан комментариями рядом с шотом: по нему skill make-video заменяет карточки настоящей графикой ([DRAW.md](DRAW.md)). Тайминги черновика совпадают с проверкой `--tts` с точностью до долей секунды.

## 14. Художественные сценарии: мистика, фантастика, серии

Инструмент вырос на фактических роликах («что будет, если…», расследования, объяснялки), где качество держится на проверенных фактах. В придуманной истории те же правила ведут к «безопасному» сценарию: угол-обзор, крючок-вопрос, энциклопедический тон, герои без желаний, повороты из ниоткуда. Поэтому у вымысла свой режим: `meta.genre: fiction` (или формат `fiction`). В нём проверка требует **библию истории** (`story:`) и следит за текстурой текста; ограничения фактического режима (≥ 4 фактов с источниками, «число в награде без факта») снимаются — числа в вымысле придуманы.

```bash
python3 vg.py script formats fiction                         # структура, архетипы углов, правила драматургии
python3 vg.py script new shadow2 --topic "…" --format fiction --style draw \
        --series "Без тени" --part 2 --of 3 --prev shadow1 --next shadow3
```

Образец по ощущению (не шаблон!): разбор ролика «Убежище №14» — [examples/shelter14.md](examples/shelter14.md). Серия «Без тени» v2 (`projects/shadow1–3`) — **антипример**: формально проходила старые проверки, но зритель не понял сюжет; по правилам §14.6 она получает 34/100.

### 14.1 Угол: парадокс, а не обзор

Перед выбором угла пройдите ≥ 3 разных **архетипа** (`research.angles[].archetype`) и для каждого назовите **парадокс** (`paradox`) — противоречие, которое держит интерес:

| Архетип | Что это | Пример |
|---|---|---|
| `what_if` Что если… | одно правило мира меняется и доводится до предела | не «как работают тени», а «что если тень уходит от хозяина» |
| `rule_break` Слом закона | знакомый закон работает иначе — со строгой логикой | одна свеча опаснее полной темноты |
| `inhuman_pov` Нечеловеческий взгляд | рассказ от лица предмета, существа, ИИ, тени | история глазами камня, который пьёт свет |
| `conceptual_bridge` Мост-метафора | чужая механика через бытовую ситуацию зрителя | свеча на столе = дверь для тени |
| `fourth_wall` Четвёртая стена | зритель — участник: пасхалка, эксперимент | «найди в первой части, где тень отстаёт» |
| `unreliable` Ненадёжный рассказчик | поворот переворачивает смысл уже сказанного | — |
| `time_loop` Петля времени | финал возвращает к началу с новым смыслом | — |
| `role_swap` Смена ролей | угроза оказывается защитой, спаситель — бедой | тень Марты не нападает, а предупреждает |
| `inheritance` Наследство / проклятие | дар или предмет с правилом и ценой | — |

Угол-лекция («обзор», «N фактов», «история создания») в вымысле — предупреждение. Выбирайте угол с парадоксом, риском для героя или сломом реальности.

### 14.2 Библия истории (`story:`)

| Поле | Что проверяется |
|---|---|
| `premise` | одно предложение «Что если …?» — без него ошибка |
| `paradox` | названо противоречие истории |
| `world_rules` | 2–4 правила (в части серии — ≤ 2 новых); у каждого `test` — проверка на герое с цифрой или сроком; каждое **показано на экране** в блоке-награде (`shown_in`), опора — факт (`basis: f2`) или «вымысел»; развязка следует из правил, нового чуда в финале нет |
| `characters` | ≥ 2 героя, у каждого `want` (чего хочет) и `fear` (чего боится), `intro` — паспорт при первом появлении («Палыч, 63 года. Ключ от двери — только у него»); главный назван в тексте диктора |
| `logline` | «<Герой, кто он> хочет/должен <цель>, но <препятствие>; если не успеет — <цена>» — без него ошибка |
| `retell` | эта часть в ≤ 3 предложениях / ≤ 45 словах, как зритель перескажет другу — без него ошибка |
| `twists` | ≥ 1 поворот; **подготовка (`setup`) раньше выстрела (`payoff`)**, выстрел — не в первых 40%; `setup` — список: улику главного поворота сейте 2–3 раза |
| `dilemmas` | ≥ 1: `{beat, who, question, options: [A, B]}` — выбор между двумя плохими вариантами |
| `stakes` | уровни по блокам растут: личное → семья → община → мир (передышка допустима) |
| `series` | `part/of`, соседние части (`prev`, `next`) — **длительности равны (±6%)**; не последняя часть кончается обрывом и называет следующую; со 2-й части — `answers`: на какой вопрос прошлой части отвечает эта |

Финал вымысла — `twist`, `cliffhanger`, `reveal` или `payoff` перед призывом; лучший финал отправляет пересматривать (пасхалка в первом кадре, петля).

### 14.3 Крючок: спекулятивный и визуальный

Для вымысла сильнее всего типы `speculative` («[время/место] + [нарушение правила мира] + [поворот против ожидания]»), `anomaly` и `visual_shock`, `result_first`, `stakes`. Крючки-лекции (`question`, `list_promise`, `contrarian`, `callout`) как основной — предупреждение.

- Плохо: «Вы когда-нибудь задумывались, куда уходят тени?»
- Хорошо: «После падения звезды полдеревни осталось без тени. Ночью тени вернулись — за остальными.»

Первый кадр — **визуальная аномалия или конфликт**, понятный без звука за секунду: люди на солнце без теней, небо не того цвета, тень, которая двигается сама.

### 14.4 Текст: покажи, а не расскажи

- **Деталь вместо оценки.** Не «было очень страшно», а «свеча погасла сама — и пламя наклонилось к стене». Проверка подсвечивает слова-оценки (`очень`, `страшный`, `жуткий`, `опасный`, `странный`…) — каждую замените тем, что видно или слышно.
- **Сенсорные детали** — звук, запах, холод/жар, свет — минимум в трёх блоках.
- **Без клише и «ИИ-слов».** Во всех сценариях: «уникальный», «невероятный», «захватывающий», «в заключение», «стоит отметить»…; в вымысле ещё «в мире, где…», «древнее зло», «таинственный», «леденящий», «представьте себе», «всё изменилось навсегда». Списки — в [`engine/script/data/story.yaml`](../engine/script/data/story.yaml).
- **Правило мира — как опыт.** Блок `rule` показывает механику схемой или последствием так, чтобы зритель мог «сыграть» по правилу сам (одна свеча → длинная тень → дверь).

### 14.5 Структура и эскалация (формат `fiction`)

| Доля | Блок | Задача |
|---|---|---|
| 7% | `hook` | правило-предупреждение зрителю (`rule_warning`) или аномалия: сразу цифра/срок и цена |
| 12% | `setup` | сцена: где и когда; герой с паспортом и целью; «ружьё» будущего поворота |
| 14% | `problem` | инцидент — сцена с репликами, личные ставки |
| 16% | `rule` | правило мира, проверенное на человеке, с цифрой; схема на экране |
| 16% | `escalation` | дилемма: спор героев короткими репликами, выбор с ценой |
| 14% | `twist` | улика, посеянная раньше, щёлкает — смысл прошлых сцен меняется |
| 11% | `cliffhanger` | новая угроза или вопрос в последней сцене |
| 10% | `cta` | вопрос-выбор по дилемме + следующая часть |

### 14.6 Ясность и драйв сюжета

Выросло из разбора образца ([examples/shelter14.md](examples/shelter14.md)) и провала «Без тени» v2: сценарий проходил все проверки, но зритель «абсолютно ничего не понял». Проверка (`engine/script/story.py`, `drama()`) теперь требует:

| Что | Поле | Порог |
|---|---|---|
| Сюжет формулируется | `story.logline`, `story.retell` | обязательны; пересказ ≤ 3 предложений и ≤ 45 слов |
| Не перегружено | правила мира + названные герои + повороты | ≤ 6 на минуту; в части серии ≤ 2 новых правил |
| Каждый блок — сцена | `beats[].scene: {when, where}` | у ≥ 60% сюжетных блоков; фразы-итоги («в ту ночь забрали ещё…», «понял правило», «оказалось, что») — предупреждение |
| Герои с паспортом | `characters[].intro` | звучит в тексте при первом появлении |
| Герои говорят | `beats[].lines: [{who, say}]` | ≥ 4 реплик, ≥ 1 обмен двух героев в одном блоке; реплика ≤ 12 слов и дословно входит в `vo` |
| Правило проверено на человеке | `world_rules[].test` | с числом, сроком или мерой |
| Есть выбор | `story.dilemmas` | ≥ 1; финальный вопрос просит выбрать сторону или выдвинуть версию |

Новый тип крючка `rule_warning` — «Если [событие], у вас [срок/мера]. Потом [последствие против ожидания]». Структура формата `fiction` перестроена вокруг сцен: крючок → сцена с героем → инцидент с репликами → правило, проверенное на человеке → дилемма-спор → улика/поворот → обрыв → вопрос-выбор. **Сюжетной части нужно 90–150 с** — в 60 секунд сцены, спор и улика не помещаются.

Реплики героев пишутся прямо в `vo` (диктор их произносит), а `lines` отмечает, чья это реплика, — для подписи говорящего на экране («ТИМУР, 24 · КУРЬЕР») и, в будущем, для отдельного голоса.

### 14.7 Роль сценариста

Пишите как сценарист качественной короткометражной фантастики («Чёрное зеркало», «Любовь, смерть и роботы», «Сумеречная зона»): одна сильная идея, доведённая до конца; герои платят за выбор; правила мира честные; ни одного пафосного эпитета там, где можно показать предмет, звук или цифру.

**Что из внешних советов не взято и почему.** Подсказки для генераторов видео («cyberpunk neon glare, volumetric fog») не подходят к нашим способам графики: в `draw` кадр собирается из актёров, поэтому визуальная анормальность описывается словами в `visual` и делается актёрами и светом (§8; [DRAW.md](DRAW.md) §10.6). Запрет форматов «N фактов» и «обзор» действует только для вымысла — для фактических роликов это рабочие форматы (`listicle`, `explainer`).
