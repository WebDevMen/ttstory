# Мануал: как делать вертикальные ролики уровня «Танкера» — от идеи до готового MP4

Этот документ объясняет, **как был сделан ролик «Мануал по выживанию: танкер»** и **как с теми же инструментами делать любые другие ролики**: с другим сюжетом, голосом, графикой и стилистикой. Качество при этом должно быть не хуже исходного.

Пример «совсем другого» ролика на том же движке: [`projects/tea`](../projects/tea/project.yaml) («3 правила чайной церемонии»). Там рисованная акварель, женский голос, светлый минималистичный интерфейс, спокойная пентатоника, лепестки сакуры и пар.

А [`projects/school`](../projects/school/project.yaml) («Один день в японской школе») сделан **вообще без нейросетевых картинок**: каждый кадр нарисован кодом из библиотеки «актёров» — персонажей, зданий, интерьеров, интерфейсов. Как это устроено — в [DRAW.md](DRAW.md) и в разделе [5.5](#55-без-генерации-своя-графика-кодом).

## 0. Способ графики: какой выбрать

У движка три способа делать картинку. Способ выбирается для каждого ролика и записывается в `meta.style` сценария (`script.yaml`).

| Способ | Что это | Документация и пример |
|---|---|---|
| `draw` — **по умолчанию** | своя графика, нарисованная кодом: библиотека актёров, камера, параллакс, анимация по словам. Без нейросетей и без расхода кредитов | [DRAW.md](DRAW.md); `projects/school`, `slots`, `superuser`, `blame` |
| `motion` | ИИ-иллюстрации (персонажи и места, генерация в Figma AI) + моушн-графика на Remotion (блоки, автоматическая вёрстка, пружинная анимация) | [MOTION.md](MOTION.md); `projects/proverbs` |
| `plates` | AI-кадры с 2.5D-параллаксом | этот мануал, §5; `projects/tanker`, `projects/tea` |
| `mixed` | сочетание способов в одном ролике | — |

Как Claude выбирает способ:

1. По словам в запросе: «своя графика», «без нейросетей», «как школа» → `draw`; «иллюстрации», «ИИ-картинки», «моушн», «как пословицы» → `motion`; «как танкер», «AI-кадры» → `plates`.
2. Если у проекта уже есть сценарий или ролик — тем способом, который там указан. Сам способ Claude не меняет.
3. Если из запроса непонятно — Claude один раз спрашивает (рекомендуя `draw`). Если спросить некого (автоматический запуск) — берёт `draw`.

Чтобы выбрать способ сразу, просто напишите его в запросе: «Сделай ролик про … своей графикой» или «… с ИИ-иллюстрациями и моушн-графикой».

## 1. Как это устроено

Готовые видеогенераторы (Veo, Kling, Runway) дают 5–10-секундные клипы. Ими трудно управлять: текст на экране, синхронизация с голосом и единый стиль получаются плохо. Здесь сделано иначе — гибридный конвейер, где **AI отвечает за красоту картинки, а код — за движение, графику, синхронизацию и звук**. Картинку шота можно взять из двух источников: AI-кадр (`plate:`) или **сцена, нарисованная кодом** (`draw:`) — тогда управляемо вообще всё, до каждого окна и движения руки персонажа:

```
 Сценарий ──► project.yaml ◄── ваши правки (всё в одном файле)
     │              │
     ▼              ▼
 AI-кадры      Озвучка (Edge TTS)  ──► тайминги каждого слова
 (Figma AI)         │
 или draw:          │     (draw: персонажи, здания, UI, карты, графики — SVG/HTML + GSAP,
 актёры кодом       │      Lottie, rough.js, D3, three.js; кадр за кадром в Chromium)
     │              ▼
     ▼         Таймлайн: сцены, шоты, метки, HUD, звуки — всё в секундах, привязано к словам
 Апскейл ×4 +       │
 карта глубины      ├──► Слой сцены: 2.5D-камера с параллаксом по глубине + туман, вода, частицы,
                    │     свет, молнии, переходы, bloom, грейдинг, зерно      (Python/OpenCV)
                    ├──► HUD и субтитры: стеклянные панели, 3D-голограммы, маркеры, кнопки
                    │     (HTML/CSS/three.js в headless Chromium, кадр за кадром)
                    ├──► Звук: голос + музыка (синтез) + амбиенс + эффекты + автозвуки HUD
                    ▼
               Финальный MP4 1080×1920, 30 fps, −14 LUFS
```

**Почему качество высокое:**
- **Картинка.** Каждый кадр — продуманная AI-иллюстрация уровня «кадр из анимационного фильма», а не генерация «на лету». Апскейл Real-ESRGAN ×4 делает её чёткой на 1080p.
- **Движение.** Камера двигается с параллаксом по карте глубины (Depth Anything V2): близкие предметы смещаются сильнее дальних. Поэтому статичная картинка выглядит как 3D-сцена. Поверх — живые слои: туман, вода, частицы, свет.
- **Синхронизация.** Каждый элемент — плашка, звук, вспышка, смена кадра — привязан к конкретному слову диктора. Ролик ощущается смонтированным вручную.
- **Графика.** Интерфейс свёрстан как сайт: настоящие шрифты с кириллицей, размытое стекло, свечение, 3D-наклоны, анимации с easing. Поэтому он чистый и «дорогой», а не налепленный в редакторе.
- **Звук.** Дизайн из десятков слоёв: океан, ветер, клики интерфейса, басовые нарастания перед сменой сцены, удары, музыка в тональности с приглушением под голос. Громкость сведена к стандарту соцсетей.

Всё детерминировано: один и тот же `project.yaml` всегда даёт тот же ролик. Правка — это изменение строки в файле и перерендер.

## 2. Два способа работы

### Способ А (рекомендуется): через Claude Code

В репозитории есть инструкция для Claude — [`.claude/skills/make-video/SKILL.md`](../.claude/skills/make-video/SKILL.md). Откройте новую сессию Claude Code с этим репозиторием и напишите, например:

> Сделай новый ролик по этому сценарию: … Стиль — мрачный нуар, голос женский.

или вызовите `/make-video` и вставьте сценарий. Claude пройдёт все шаги сам: напишет `project.yaml`, сгенерирует кадры через Figma AI (если подключён Figma), подготовит их, расставит эффекты и графику, отрендерит превью, проверит, доделает финал, закоммитит и пришлёт файл. Ваша роль — давать обратную связь: «плашку правее», «музыку бодрее», «голос медленнее».

### Способ Б: вручную

1. `./setup.sh` — один раз.
2. `python3 vg.py new my_video` — копия шаблона.
3. Положите кадры в `projects/my_video/plates/`, пропишите `project.yaml`.
4. `python3 vg.py voice my_video && python3 vg.py compile my_video` — проверить длительность.
5. `python3 vg.py prep my_video` → `python3 vg.py grid my_video` — снять координаты.
6. `python3 vg.py preview my_video --shots` — посмотреть кадры, поправить, повторить.
7. `python3 vg.py all my_video` → готовый `out/my_video.mp4`.

## 3. Установка

Нужно: Linux или macOS, Python 3.10+, Node.js 18+, ffmpeg, около 2 ГБ места. В облачной сессии Claude Code всё это есть.

```bash
./setup.sh                    # venv + пакеты, Playwright/Chromium, модели ESRGAN и Depth Anything (≈170 МБ)
source .venv/bin/activate
python3 vg.py doctor          # всё должно быть с ✓
```

Сеть нужна для озвучки (Microsoft Edge TTS, бесплатно) и для первой загрузки моделей. Рендер работает локально.

## 4. Шаг 1. Сценарий

Хороший сценарий для Shorts/TikTok/Reels — половина успеха. Для сценария есть отдельный инструмент — **[SCRIPTING.md](SCRIPTING.md)**: исследование темы с источниками, крючки, текст по секундам, раскадровка, упаковка, автоматическая проверка (`python3 vg.py script …`) и черновик `project.yaml` из готового сценария. Ниже — короткая версия правил, по которым написан «Танкер»:

**Хронометраж.** При темпе `+20%` диктор произносит примерно **2.5 слова в секунду**. 60 секунд — это **около 140–150 слов**, 30 секунд — около 75.

**Структура (5 блоков по 8–14 секунд):**
1. **Крючок (0–8 с).** Сразу ситуация «представь» или провокация: «Ты пьёшь чай неправильно». Первые 2 секунды решают, досмотрят ли.
2–4. **Основная часть.** Каждый блок — одна мысль с понятным заголовком («ЧТО ДЕЛАТЬ», «ЧЕГО НЕЛЬЗЯ», «ПРАВИЛО №2»). Внутри блока 1–2 конкретных образа, которые можно показать.
5. **Финал с вовлечением.** Вопрос или выбор («A или B?») и призыв «напиши в комментариях». Это главный двигатель охватов.

**Как писать текст для озвучки:**
- Короткие фразы. Тире `—` даёт паузу, многоточие `…` — драматическую паузу.
- Пишите `ё`, где важно ударение: «прогниёт», «рискнёшь».
- Цифры — словами, если нужна конкретная форма: «восьмидесяти градусов».
- Каждый визуальный акцент привязывайте к слову: «Второе — забаррикадируй…» на слове «Второе» сменит кадр.

**Совет:** сначала прогоните `voice` и `compile` только с текстом и одним временным кадром. Сразу станет видна точная длительность, и текст можно подрезать до генерации картинок.

## 5. Шаг 2. Стиль и ключевые кадры

### 5.1 Сколько кадров

Один кадр («плита») — это один шот длиной **2.5–13 секунд**. Динамичному ролику на 60 секунд нужно **8–10 кадров** («Танкер» — 9). Спокойному на 30 секунд — 5 («Чай»). Шоты длиннее 8 секунд оживляйте HUD-событиями и эффектами, чтобы картинка не «застывала».

### 5.2 «Библия стиля»: одна формула на все кадры

Чтобы кадры выглядели как один фильм, у всех промптов должен быть **общий хвост стиля** и **одинаково описанные повторяющиеся объекты** (руки героя, перчатки, одежда, главный предмет).

Формула промпта:
```
Vertical 9:16 frame. [РАКУРС: First-person POV / close-up / top-down / wide]
[ЧТО В КАДРЕ: герой/руки + предмет действия + окружение, 2–3 предложения, конкретно]
[СВЕТ И АТМОСФЕРА: soft volumetric light, fog, golden hour, neon accents…]
[СТИЛЬ — одинаковый для всех кадров]
No text, no letters, no UI, no watermark[, no people].
```

Стили, проверенные на этом движке:
- **Стилизованный 3D CGI** («Танкер»): `Stylized 3D animated feature film still, high-end CGI render, clean smooth surfaces, soft volumetric lighting, cinematic depth of field, teal-emerald color grading.`
- **Рисованная акварель** («Чай»): `Hand-painted anime background art, cozy Japanese animated film style, soft watercolor and gouache textures, warm gentle light, richly detailed.`
- Ещё варианты: `cinematic photorealistic film still, 35mm, anamorphic` (документалка), `retro 1980s synthwave illustration, neon grid` (ретро), `dark noir graphic novel, ink and halftone` (нуар), `isometric low-poly 3D, pastel colors` (обучалки), `oil painting, dramatic chiaroscuro` (история).

**Повторяющийся объект** описывайте в каждом промпте одними и теми же словами. Пример из «Танкера»: `two hands in sleek black-and-graphite tactical gloves with small glowing teal accents`.

**Важное для движка:**
- Всегда **без текста** (`No text, no letters`) — все надписи делает HUD.
- **Чёткий передний и задний план** — тогда параллакс по глубине выглядит объёмно. Хорошо работают POV с руками или предметом на переднем плане и пейзаж с горизонтом.
- **Оставляйте место под графику:** небо, стена, тёмная зона вверху или по центру.
- Объекты, которые будут «жить», должны быть **явно видны**: вода (рябь), неон (мерцание), пар (частицы), окно (молнии), фонарь (луч).

### 5.3 Где генерировать

- **Figma AI** (так сделаны оба ролика): `generate_image`, модель `gemini-3.1-flash-image`, запрос `width: 1152, height: 2048` (выдаёт 768×1376, 9:16). Claude делает это сам, если подключён Figma. Генерации тратят AI-кредиты вашего плана Figma (на «Танкер» и «Чай» ушло 9 + 5 генераций).
- **Любой другой генератор** (Midjourney `--ar 9:16`, DALL·E, Flux, Leonardo, Ideogram…) — главное, чтобы картинка была вертикальной 9:16. Подойдёт любое разрешение от 768 px по ширине.
- **Свои фото и рендеры** тоже подходят: движок не различает, откуда кадр.

Файлы кладите в `projects/<id>/plates/` с понятными именами (`p1_deck.png`, `d2_kettle.png`) и **записывайте промпты** в поле `prompt` шота или в `plates/PROMPTS.md` — чтобы потом можно было перегенерировать похожие.

### 5.4 Отбор

Посмотрите все кадры вместе (контактный лист). Отбракуйте кадры с кривыми руками, лишними пальцами, текстом-абракадаброй на видном месте и «выпадающие» по цвету. Перегенерировать один кадр дешевле, чем потом маскировать дефект.

### 5.5 Без генерации: своя графика кодом

Если нужна графика, которой можно управлять полностью (объяснялки, инфографика, «что будет, если…», моушн-дизайн с персонажами), шот описывается не картинкой, а сценой из актёров:

```yaml
shots:
  - id: street
    draw:
      world: [3000, 1920]                                   # мир шире экрана — панорама
      camera: {keys: [{t: 0, x: 540}, {t: end, x: 1560, ease: linear}]}
      layers:
        - {actor: sky, hour: 7.5, par: 0}                   # утро; hour можно анимировать — закат, ночь
        - {actor: train, x: -1400, y: 900, viaduct: true, par: 0.55, anim: [{at: "@поезде-0.6", dur: 3.6, x: 2600, ease: linear}]}
        - {actor: house, x: 560, y: 1180, seed: 2}
        - {actor: street, x: -200, y: 1180, w: 3400}
        - {actor: person, id: kid, view: side, x: 1180, y: 1228, look: {age: kid, hat: kid, bag: randoseru}, walk: 2.6, anim: [{at: "@Даже", dur: 3.4, x: 1880, ease: linear}]}
        - {actor: callout, space: screen, x: 640, y: 520, at: "@первоклассники", target: "kid.top", title: "1 КЛАСС"}
```

Библиотека: ~45 актёров (персонажи с позами и мимикой, японская школа, дома, улица, поезд, сакура, небо по часам суток, класс с учениками, доска с мелом, шкафчики, обед, телефон, батарея, выноски, бейджи, карточки, графики D3, карты, 3D, Lottie, рисунок «от руки», частицы). Всё анимируется по словам, а недостающее легко дописать (свой актёр — один JS-файл в проекте). Полное описание — [DRAW.md](DRAW.md).

## 6. Шаг 3. Проект и озвучка

```bash
python3 vg.py new my_video            # projects/my_video/project.yaml из шаблона
# или скопировать готовый проект как основу:
python3 vg.py new my_video --from tea
```

Минимальный `project.yaml`:
```yaml
title: "Мой ролик"
voice: {voice: ru-RU-SvetlanaNeural, rate: "+12%"}
theme: {preset: minimal, accent: pink, captions: {style: box_word, uppercase: false}}
scenes:
  - id: hook
    text: Ты пьёшь чай неправильно. Вот три правила, которые знает каждый мастер.
    shots:
      - {id: garden, plate: d1_garden}
```

```bash
python3 vg.py voice my_video          # синтез по сценам, кэшируется (повторно — только изменённые сцены)
python3 vg.py compile my_video        # покажет длительность, тайминги сцен и шотов
```

**Голос:** `ru-RU-DmitryNeural` (уверенный мужской), `ru-RU-SvetlanaNeural` (тёплый женский), `ru-RU-DariyaNeural` (молодой женский). Для историй лучше мультиязычные голоса Edge — они читают по-русски с более живой интонацией: `fr-FR-RemyMultilingualNeural` (рассказчик), `en-US-AndrewMultilingualNeural`, `en-US-AvaMultilingualNeural`, `en-US-EmmaMultilingualNeural` (реплики героев); офлайн — локальные `vosk:*` (REFERENCE §2). Голос выбирает пользователь: пришлите ему 5–8 коротких образцов одного куска сценария. `rate: +15…25%` — динамичный TikTok-темп, `+5…10%` — спокойный. `pitch: -4Hz` делает голос чуть ниже и солиднее.

**Если ударение неверное:** поставьте `ё` или перепишите фразу. Если пауза слишком длинная или короткая — `voice.pause_long/pause_short`, `keep_pauses: {слово: 0.45}`, `gap_after` у сцены.

## 7. Шаг 4. Таймлайн

Главная идея движка: **время задаётся словами, а не секундами.**

```yaml
cues:
  door_slam: "@крепость.end+0.05"     # метка = конец слова «крепость» + 0.05 с
shots:
  - id: corridor
    start: "@Второе-0.12"             # шот начинается за 0.12 с до слова «Второе»
hud:
  - {component: stamp, at: "@cue:door_slam", text: МОСТИК ЗАПЕРТ}
sfx:
  - {sound: slam, at: "@cue:door_slam", gain: -5}
```

Если поменяете текст или голос, всё автоматически «переедет» за словами. Полный синтаксис ссылок — в [REFERENCE §0](REFERENCE.md#0-соглашения).

**Ритм монтажа:**
- Меняйте шот **за 0.1–0.2 с до ключевого слова** (`@Слово-0.12`): глаз видит новый кадр ровно к слову.
- HUD-плашки появляйтесь **на слове** (`@Слово-0.05`), заголовки — **чуть раньше**.
- Сильным ударам (дверь, молния) давайте **паузу в голосе**: `gap_after` или `keep_pauses`.

## 8. Шаг 5. Подготовка кадров

```bash
python3 vg.py prep my_video           # ≈1–4 мин на кадр (CPU), параллельно; готовые пропускаются
python3 vg.py grid my_video           # сетки координат → build/my_video/grid/grid_sheet.jpg
```

`prep` делает для каждого кадра апскейл ×4 (Real-ESRGAN) с уменьшением до 1296×2304 и карту глубины (Depth Anything V2). Глубину стоит проверить: светлое — близко, тёмное — далеко.

Сетка нужна, чтобы снять координаты: где горизонт, где окно, откуда идёт пар, где лампа. Всё это задаётся в пикселях плиты (жёлтые линии — каждые 100 px). При `z: 1` экран показывает центральную область 1080×1920.

## 9. Шаг 6. Камера и эффекты

### 9.1 Камера — главное, что делает кадр «живым»

Рецепты (вставляйте в шот):

```yaml
# «Облёт»: начать на дальнем плане и опуститься к рукам (интро «Танкера»)
camera:
  keys: [{t: 0, z: 1.24, x: 705, y: 915}, {t: 4.6, z: 1.02, x: 648, y: 1175}, {t: end, z: 1.07, y: 1150}]
  sway: {x: 10, y: 8, roll: 0.8, freq: 0.12}
  parallax: {px: 16, py: 8, freq: 0.12, k: [0, 0.05]}

# Медленный наезд (универсально)
camera: {keys: [{t: 0, z: 1.0}, {t: end, z: 1.1}], sway: {x: 5, y: 4, roll: 0.4, freq: 0.15}, parallax: {px: 10, k: [0, 0.06]}}

# Предмет в руке: рука стоит, фон «плывёт» (ракетница, компас, чаша)
camera: {keys: [{t: 0, z: 1.0}, {t: end, z: 1.08}], sway: {x: 8, y: 7, roll: 0.9, freq: 0.22}, parallax: {px: 22, py: 10, d0: 0.82}}

# Проход по коридору
camera: {keys: [{t: 0, z: 1.0}, {t: end, z: 1.15, ease: linear}], bob: {freq: 1.9, x: 5, y: 7, roll: 0.6}, parallax: {k: [0, 0.24]}, push_end: {dur: 0.35}}

# Взгляд вниз с закручиванием (люк, чаша сверху)
camera: {keys: [{t: 0, z: 1.0, roll: 0}, {t: end, z: 1.17, roll: 3}], parallax: {k: [0, 0.09]}}

# Удар: тряска на метке
camera: {shakes: [{at: "@cue:slam", amp: 30, dur: 0.55}]}
```

### 9.2 Эффекты — по сюжету кадра

| В кадре есть… | Добавьте |
|---|---|
| море, озеро, лужа | `water` (+ `glints` на закате, `ripples` от капель) |
| воздух, даль, утро | `fog` (цвет под палитру кадра), `god_rays` при солнце |
| неон, экраны, лампы | маска по насыщенности + `mask_flicker` / `mask_pulse`, `glow` |
| фонарь, прожектор | маска `cone` + `mask_flicker`, пыль `drift` с `boost_mask` |
| дождь, снег, лепестки | `rain`, `particles: fall_loop` (`shape: petal`) |
| пар, дым | `particles: smoke` |
| огонь, угли | `glow` с быстрым `pulse`, искры `emanate` |
| магия, споры, светлячки | `particles: emanate` + `glow` + `haze` |
| окно/иллюминатор ночью | `window` + `lightning` |
| струи, водопад, блики на плёнке | маска по цвету + `flow` |
| удар, взрыв | `flash`, `shakes`, `particles: burst`, `exposure` |

Начинайте с 2–4 эффектов на шот. Лучше несколько точных, чем много случайных. Плотность тумана — 0.1–0.3, альфа частиц — 0.05–0.3: эффекты должны **подчёркивать** картинку, а не закрывать её.

`look` (bloom и грейдинг) задаёт характер: мягкое свечение и чуть больше контраста для кино, `sat: 1.05–1.1` для яркости.

Переходы: динамика — `whip_x/whip_y/zoom/glitch/slam`, спокойствие — `dissolve/fade/dip`, кульминация — `flash`.

## 10. Шаг 7. Графика (HUD) и субтитры

### 10.1 Тема

`theme.preset` задаёт шрифты, форму панелей, свечение и обводки сразу для всех компонентов:
- `scifi` — тёмное стекло, неон, сканлайны, Exo 2 + JetBrains Mono («Танкер»);
- `minimal` — светлые карточки, Montserrat, без неона («Чай»);
- `pop` — жирный Unbounded, плотные цветные плашки, чёрные обводки и жёсткие тени;
- `documentary` — Playfair Display с засечками, тонкие линии, тёмные полупрозрачные карточки.

Цвет у каждой сцены свой (`accent`) — это помогает зрителю «читать» структуру: зелёный — «что делать», красный — «нельзя», оранжевый — финал.

### 10.2 Что показывать

На каждую сцену — **1 маркер раздела + 1–3 информационных элемента**, привязанных к словам:
- заголовок (`title`) — в интро;
- маркер раздела (`marker`) — в начале каждого блока;
- конкретика из текста: цифра → `counter`/`stats`/`meter`, предупреждение → `chip`/`alert`/`prohibit`/`hazard`, схема → `holo3d`, перечисление → `list`;
- объект в кадре → `target`, `prohibit` или `hazard` с `anchor` (прилипает к объекту и двигается с камерой);
- финал → `choices` + `cta`.

### 10.3 Безопасные зоны TikTok/Reels/Shorts

Интерфейс площадок перекрывает верх (~0–150 px), правую колонку кнопок (x > 940 на высоте 800–1550) и низ (~1550–1920, подпись и ник). Поэтому:
- маркеры — y ≈ 214;
- панели — y ≈ 300–900;
- субтитры — y ≈ 1200–1320;
- CTA — не ниже 1450.

### 10.4 Субтитры

Генерируются автоматически из слов диктора: по 2–4 слова, активное слово подсвечено. Стили: `neon_word` (жирный курсив с цветным активным словом), `box_word` (активное слово в цветной плашке), `minimal`, `karaoke` (сказанное закрашивается), `outline_pop`. Позицию можно задать для всего ролика (`theme.captions.top`), сцены (`captions_top`) или шота. Когда на экране кнопки выбора, субтитры лучше скрыть (`captions.hide`).

## 11. Шаг 8. Звук

Звук делает половину «дороговизны». Без единого стороннего файла собираются четыре слоя:

1. **Голос** — очищается, сжимается, слегка «озвучивается» комнатой и всегда звучит громче остального.
2. **Музыка** — синтезируется в заданной тональности по секциям-стилям (§8.1 справочника) и автоматически приглушается под голосом. Свой трек (с правом использования) можно подключить через `music.file`.
3. **Амбиенс** — по шотам: океан, ветер, дождь, гул, птицы, огонь… Сцена сразу «звучит» как место.
4. **Эффекты** — автоматические для HUD и переходов плюс свои события в `sfx` для сюжетных моментов: удар двери, гром, сердцебиение, скрежет, капли, шаги.

Правила хорошего сведения (они уже заложены в уровни по умолчанию):
- голос примерно на 8 дБ громче музыки и амбиенса;
- перед сменой сцены — короткое нарастание (riser), на смене — удар;
- в момент драмы — тишина: секция `sub` или `silence`, только сердцебиение;
- итог −14 LUFS: так площадки не будут ни глушить, ни «раздувать» ваш звук.

`python3 vg.py audio <id> --stems` сохраняет дорожки по отдельности — удобно, если хотите досвести звук в своём редакторе.

## 12. Шаг 9. Превью, рендер, контроль качества

Откройте `build/my_video/preview/preview.jpg` и проверьте: композицию, читаемость надписей, попадание якорей в объекты, наложения элементов, цвет. Правьте `project.yaml` и повторяйте — это быстро.

Для нарисованных шотов перед полным рендером обязательна проверка вёрстки (стандарт аккуратности — [DRAW.md §10.1](DRAW.md#101-аккуратность-стандарт-вёрстки-обязателен-для-каждого-ролика)):
```bash
python3 vg.py layout my_video     # обрезанный и наезжающий текст, субтитры поверх графики, зоны площадки, «почти по центру»
```
В рендер — только при 0 ошибок и не больше 3 осознанных предупреждений. Проверка смотрит и вёрстку, и пропорции, пол, позы, контраст, рывки и дрожание ([DRAW.md §10.1–10.3](DRAW.md#102-слой-раскладки-зоны-автоподгонка-стопки)).

Затем раскадровка на согласование — по три готовых кадра каждого шота:
```bash

```
После правок движка или актёров библиотеки: `python3 vg.py bench` (сравнение с эталонами, [DRAW.md §10.5](DRAW.md#105-испытательный-стенд-актёров)).

Финал:
```bash
python3 vg.py all my_video        # или по шагам: scene → audio → hud → mux → qa
```

Время на 4-ядерной машине без GPU (60-секундный ролик): слой сцены ≈ 6–10 мин, HUD ≈ 15–20 мин, звук ≈ 1 мин, сборка ≈ 4 мин. Итог: `out/my_video.mp4` (H.264, 1080×1920, 30 fps, 8 Мбит/с, AAC −14 LUFS) и контактные листы `build/my_video/qa/sheet*.jpg` — по кадру в секунду, чтобы быстро просмотреть весь ролик.

## 14. Чек-лист качества

Перед публикацией (Claude проходит его сам):

**Сценарий и голос**
- [ ] Крючок в первые 2 секунды, финал с вопросом или выбором и CTA.
- [ ] Длительность в цели (30/45/60 с), темп ровный, ударения верные.

**Картинка**
- [ ] Все кадры в одном стиле, без текста-абракадабры и дефектов рук.
- [ ] В каждом шоте есть движение камеры и минимум один «живой» слой.
- [ ] Края плиты не видны (`z ≥ 1`, центр в безопасных пределах).
- [ ] Переходы попадают в слова, нет «пустых» кадров.
- [ ] Правдоподобие сцены (для любого способа — `draw`, `motion`, `plates`): ничего не висит в воздухе, у зданий, людей, машин есть земля под основанием; фон не пустой — 3+ плана глубины, дымка, дальние планы светлее; один источник света; нет «штампа» одинаковых объектов; мир единый (в руинах — пыльные, ржавые машины). Для ИИ-кадров: в промпте просите «layered background with distant city / hills, atmospheric haze, objects firmly on the ground», при отборе бракуйте кадры с парящими предметами и пустым фоном. Подробно — [DRAW.md §10.6](DRAW.md#106-глубина-опора-и-проработанный-фон).

**Графика**
- [ ] `vg.py layout`: 0 ошибок, не больше 3 осознанных предупреждений (для draw-шотов).
- [ ] Поля ≥ 28 px от краёв, центрированное — ровно по оси, стопки — на одной оси с одинаковым шагом.
- [ ] 3–4 размера шрифта на ролик, ничего мельче 27 px, длинные заголовки не упираются в края.
- [ ] Ничто не съезжает и не разъезжается при анимации и движении камеры (начало, середина и конец каждого шота).
- [ ] Персонажи и предметы соразмерны (`px_per_m` для «реальных» сцен), стоят на полу (`floor`), позы естественные.
- [ ] У каждого плана своя земля с тем же `par`, основания утоплены в неё; при движении камеры ни одна щель не открывается (`vg.py layout` → `[support]`, `[backdrop]`).
- [ ] Раскадровка (`vg.py storyboard`) согласована до полного рендера.
- [ ] Элементы не перекрывают друг друга и важные части кадра.
- [ ] Всё в безопасных зонах: маркеры y ≈ 214, субтитры ≈ 1250, CTA ≤ 1450.
- [ ] Якоря попадают в объекты на протяжении всего шота.
- [ ] Субтитры читаются на светлых и тёмных кадрах.

**Звук**
- [ ] Голос разборчив поверх всего, нет внезапно громких эффектов.
- [ ] На каждом визуальном ударе есть звук, на драме — тишина.
- [ ] `qa`: Integrated ≈ −14 LUFS, Peak ≤ −1.5 dBTP.

**Файл**
- [ ] 1080×1920, 30 fps, H.264 + AAC, размер < 100 МБ (для GitHub) / < 287 МБ (TikTok).

## 15. Разбор «Танкера»

| Блок | Решение | Почему |
|---|---|---|
| Интро | старт на затопленных небоскрёбах, плавный спуск к рукам в перчатках | интрига: сначала мир, потом «ты в нём» |
| Показатели | `stats` со счётчиками на слове «Вода» | конкретика превращает текст в «игровой интерфейс» |
| «Ты не один» | красная вспышка рамки и уголков, сердцебиение | микро-шок для удержания |
| Заголовок | `title` с расшифровкой букв, райзер и бум | ставит «главу», громкий акцент |
| Что делать | 3 шота: тент (дождь и капли) → коридор (шаги, мерцающий фонарь) → дверь (скрип, удар, штамп) | динамика под текст, каждое действие видно |
| 3D-схемы | дистиллятор и голокарта танкера (three.js) | «вау»-момент: настоящая 3D-графика в интерфейсе |
| Чего нельзя | знак «запрещено», прилипший к ракетнице; споры из люка; DANGER-табличка; «3 вдоха», гаснущие на словах | красный акцент сцены, все предупреждения визуализированы |
| Угрозы | течь со струями и рябью; иллюминатор: свет гаснет на «выключи», молния на «дыши» раскрывает существо | драматургия «тишина → удар»; голос делает паузу под удар |
| Финал | закат, компас, метки «мегаполис» и «шторм», кнопки A/B, CTA | открытый вопрос — главный триггер комментариев |

Все тайминги, эффекты и звуки «Танкера» описаны в [`projects/tanker/project.yaml`](../projects/tanker/project.yaml). Это лучший учебный пример: каждую строку можно менять и смотреть, что выходит.

## 16. Проблемы и решения

| Симптом | Причина и решение |
|---|---|
| `voice`: CERTIFICATE_VERIFY_FAILED | прокси с подменой сертификатов: `setup.sh` добавляет CA в certifi, движок тоже делает это сам (`/root/.ccr/ca-bundle.crt` или переменная `VG_EXTRA_CA`) |
| `word 'X' not found in scene` | ссылка `@X` не совпала со словом: проверьте написание (ё/е не важны) и сцену, используйте `@сцена/слово` |
| виден край кадра / «растянутые» полосы | слишком маленький `z` или большой сдвиг `x/y`; уменьшите `parallax.px` или `k` |
| «каша» на краях предметов при движении | слишком сильный параллакс: `px ≤ 20`, `k ≤ 0.25`; для портретов и рук — `d0` около глубины объекта |
| эффект не там | координаты в пикселях плиты: сверьтесь с `vg.py grid`; маску проверьте мягче или жёстче |
| HUD-элемент не появился | `at` позже `until`, или ссылка указывает на другую сцену; смотрите `compile` и `preview` |
| `holo3d`/WebGL пустой | нужен Chromium с SwiftShader (ставится `setup.sh`); проверьте `vg.py doctor` |
| фоновая задача «убита» по таймауту | запускайте с большим таймаутом; `prep`/`voice` продолжат с места остановки |
| звук «пережат» | снизьте `gain` громких событий (гром, удары) или `music.gain`; проверьте `--stems` |
| файл > 100 МБ для GitHub | `vg.py mux <id> --maxrate 6M` или меньше зерна (`post.grain: 0.012`) |

## 17. Расширение движка

- **Новый актёр для `draw:`:** объект `{origin, create(p, H, item) → {el, w, h, update(t, item), anchor}}` в `engine/hud/draw/actors/*.js` (подключить в `actors/index.js`) или прямо в проекте — `projects/<id>/actors/*.js`. Подробно — [DRAW.md §9](DRAW.md#9-свои-актёры-проекта).
- **Новый эффект:** функция в `engine/scene.py` с декоратором `@effect("имя")` (или `@displace` для смещений). Получает `ctx` (картинка, глубина, маски, камера, время).
- **Новый HUD-компонент:** объект `{create(p, H) → {el, update(t, s)}}` в `engine/hud/components/*.js` и экспорт в `components/index.js`. Стили — в `base.css`.
- **Новая тема:** `engine/hud/themes/<name>.css` переопределяет CSS-переменные (`--font-display`, `--panel-bg`, `--glow`, …).
- **Новая 3D-модель:** `engine/hud/models/<name>.js` по образцу `globe.js` плюс строка в `models/index.js`.
- **Новый звук или амбиенс:** функция в `engine/audio.py` с `@sound("имя")` / `@ambience("имя")`.
- **Новый музыкальный стиль:** ветка `elif st == "..."` в `Music.render`.

Справочник по всем параметрам: [REFERENCE.md](REFERENCE.md).
