# 3D-графика (`3d`, актёр `world3d`) — экспериментальный способ

Настоящая трёхмерная сцена на **three.js** (r170, лежит в `engine/hud/vendor/`, работает офлайн) вместо плоской нарисованной картинки. Свет и тени считаются физически: солнце по времени суток, мягкие тени, отражения неба, дымка к горизонту. Камера летает в 3D по ключам, привязанным к словам диктора.

Примеры:
- [`projects/mayak3d`](../projects/mayak3d/project.yaml) («Почему маяки в полоску?», 10 с) — всё нарисовано кодом, стиль low-poly: остров с маяком, море с волнами, лодка на волнах, облака, горы в дымке, птицы.
- [`projects/ruins3d`](../projects/ruins3d/project.yaml) («Город без людей», 25 с) — постапокалипсис из **готовых бесплатных ассетов**: сканированные модели и PBR-текстуры Poly Haven, HDRI-свет, затенение в углах (GTAO), глубина резкости, пыль, трава из трещин, ржавеющие вещи, осыпающаяся стена.

Статус: **тест**. Способ встроен в обычный конвейер draw, поэтому всё остальное (2D-надписи, выноски, HUD, субтитры, эффекты сцены, звук, переходы) работает как в любом draw-ролике.

---

## 1. Как это устроено

```
draw-шот
 └─ layers:
     ├─ actor: world3d     ← весь экран — один WebGL-холст: 3D-мир, камера, свет
     ├─ actor: text        ← обычные 2D-актёры поверх (заголовки, бейджи)
     └─ actor: callout     ← выноски цепляются за 3D-объекты: target: "w.lh.top"
```

- Код: `engine/hud/three/kit.js` (мир: рендерер, небо, солнце, тени, туман, камера, постобработка), `engine/hud/three/props.js` (природа и простые объекты), `engine/hud/three/props_city.js` (город, руины, готовые модели), `engine/hud/three/assets.js` (загрузка моделей, текстур, HDRI), актёр — `engine/hud/draw/actors/three3d.js`.
- Официальные дополнения three.js (r170, `examples/jsm`: загрузчики glTF/FBX/HDR, постобработка, утилиты) лежат в `engine/hud/vendor/three-addons/`; в своём коде: `import { GLTFLoader } from "three/addons/loaders/GLTFLoader.js"`.
- Рендер — тот же `vg.py draw` (Chromium без экрана, WebGL через SwiftShader на процессоре). Скорость ≈ 3–6 с на кадр в одном потоке; 10-секундный ролик — несколько минут.
- Детерминированно: всё (волны, птицы, камера, вращение луча) — функция времени `t`.
- Единицы — **метры**, ось `y` вверх, камера обычно смотрит в сторону `-z`. Солнце встаёт на востоке (`+x`), днём на юге (`-z`).

## 2. Шот

```yaml
draw:
  layers:
    - actor: world3d
      id: w                                  # для якорей: "w.<id объекта>.<точка>"
      sky: {hour: 15.5}                      # время суток → цвета неба, солнце, тени, дымка
      shadow: {size: 30, center: [0, 0, 0], map: 2048}   # область теней (м) вокруг center
      camera:
        keys:
          - {t: 0, pos: [44, 4, 58], look: [0, 14, 0], fov: 36}
          - {at: "@полоску", pos: [30, 8, 56], look: [0, 15, 0]}
          - {t: end, pos: [20, 12, 50], look: [0, 15, 0], fov: 32}
      objects:
        - {prop: sea, wave: 0.45}
        - {prop: island, radius: 15, height: 5}
        - {prop: lighthouse, id: lh, pos: [0, -0.3, 0], ground: true, height: 13}
        - {scatter: tree, kind: pine, n: 10, ring: [0, 0, 6, 11], min_h: 2.2}
    - {actor: callout, target: "w.lh.top", x: 250, y: 330, title: "МАЯК"}
```

| Ключ `world3d` | Описание |
|---|---|
| `sky` | `hdri: "ph:<id>"` — настоящее небо-панорама (свет и отражения; `backdrop: false` — светит только HDRI, видимое небо — свой градиент `zenith/horizon`), `hdri_rot`, `bg` (яркость фона), `fog_color`, `sun_color`, `sun_size`; `hour` (0–24), `zenith`, `horizon` (свои цвета), `fog` (плотность дымки, день ≈ 0.002, туман 0.01), `sun` / `ambient` / `env` (множители света), `elev`, `az` (солнце вручную, °), `exposure`, `stars`, `sun_disc: false`. Любое поле — дорожка (`hour: [{at: 0, v: 17}, {at: "@ночь", v: 21, dur: 2}]` — закат прямо в кадре) |
| `camera` | `keys: [{t | at, pos, look, fov, roll, ease}]` — плавный путь через все ключи (сплайн). `t` — секунды от начала шота (`end`, `end-0.5`), `at` — абсолютное время (`"@слово"`). Или `orbit: {center, radius, height, from, to, radius_to, height_to, look_y, fov}` — облёт (градусы). Плюс `sway: {amp, freq}` (ручная камера, м), `shakes: [{at, amp, dur}]` |
| `shadow` | `size` (полуширина области теней, м), `center`, `map` (2048/4096), `soft`; `false` — без теней |
| `objects` | список объектов (§3) |
| `scenery` | общий «декор» нескольких шотов (YAML-якорь `- *street`): ставится перед `objects`, вложенные списки разворачиваются |
| `post` | постобработка: `ao: {radius, intensity}` (GTAO — мягкое затенение в углах, щелях, под предметами; `false` — выкл.), `dof: {focus, aperture, maxblur}` (глубина резкости: `focus` — метры от камеры или id объекта) |
| `modules` | свои 3D-объекты проекта: `[mine.js]` → `projects/<id>/three/mine.js` (§5) |
| `exposure` | общая яркость |

## 3. Объект

| Ключ | Описание |
|---|---|
| `prop` | имя объекта из библиотеки (§4) или своего модуля |
| `id` | имя для якорей: `w.<id>` (верх), `w.<id>.top`, `w.<id>.lamp`, `w.<id>.center`… |
| `pos` | `[x, y, z]`, м. Может быть дорожкой: `pos: [{at: "@плывёт", v: [-20, 0, 16]}, {at: "@берег", v: [-6, 0, 8], dur: 3}]` |
| `ground: true` | поставить на землю: `y` = высота рельефа под объектом + `pos[1]` (отрицательный `pos[1]` — утопить основание) |
| `rot` | поворот вокруг вертикали (°) или `[x, y, z]` |
| `scale` | число или `[x, y, z]` |
| `at`, `until` | когда объект в кадре; `enter: grow / rise / drop`, `enter_dur`. **`at` занят** — параметр времени события внутри объекта называйте иначе (`fall_at`) |
| остальные | параметры объекта (у маяка `stripes`, `plain`, `lamp`, `beam`…) — каждый может быть дорожкой |

**Разброс** — много однотипных объектов на рельефе: `{scatter: tree, n: 12, ring: [cx, cz, r0, r1] | area: [x0, z0, x1, z1], min_h, max_h, avoid: [[x, z, r]], scale_range: [0.8, 1.25], seed, …параметры}`. Объект разброса ставится на землю сам; `min_h`/`max_h` — только выше/ниже заданной высоты (деревья — не в воде, камни — у кромки). Разброс должен идти в списке **после** земли/острова.

| `dust` | пыль в воздухе, ловит свет: `box, n, size, opacity, color, wind` | — |
| `pole`, `wires` | столб с траверсой; провисшие провода через точки | `top, arm_l…` |

Стиль библиотеки §4 — **low-poly с физическим светом** (гранёные поверхности, мягкие тени, PBR-материалы). Под каждым стоящим объектом — мягкая контактная тень.

## 5. Готовые ассеты: модели, текстуры, HDRI (бесплатно, CC0)

Проект перечисляет нужное в `project.yaml`, команда скачивает в общий кэш `assets3d/` (в git не попадает, повторно не качает):

```yaml
assets3d:
  res: 1k                                     # разрешение текстур: 1k хватает для вертикального кадра
  models: [covered_car, old_tyre, old_gas_mask]   # polyhaven.com/models — id из адреса страницы
  textures: [road_damaged, broken_brick_wall]     # polyhaven.com/textures — PBR: цвет, нормали, шероховатость/AO
  hdri: [industrial_sunset_02_puresky]            # polyhaven.com/hdris — небо-панорама для света
  kenney: [animated-characters-survivors]         # kenney.nl/assets/<имя> — целый пак
  files: {other/thing.glb: https://…}             # любой другой CC0-файл по ссылке
```

```bash
python3 vg.py assets3d <id>          # скачать (≈ 2–5 МБ на модель в 1k)
```

В сцене: модель — `{prop: model, src: "ph:covered_car", height: 1.5}`, текстура — параметр `tex: "ph:road_damaged"` у `road`, `ruin`, `rubble`, `pole`…, небо — `sky: {hdri: "ph:…"}`. В своём коде: `pbr("ph:<id>", {size, tint})` — материал, `worldUV(geometry)` — развёртка в метрах.

| Источник | Что там | Как получить |
|---|---|---|
| **Poly Haven** | ~520 сканированных моделей (мебель, инструменты, бочки, машины, камни, растения), ~600 PBR-текстур, ~900 HDRI. Реализм, лицензия CC0 | автоматически: `models / textures / hdri` |
| **Kenney** | стилизованные low-poly паки (персонажи с анимацией, город, техника), CC0 | автоматически: `kenney: [<имя пака>]` (FBX/GLB внутри пака) |
| **Quaternius** | low-poly паки (зомби-апокалипсис, люди с анимацией, sci-fi), CC0 | только вручную: паки лежат на Google Drive — скачать, положить в `assets3d/quaternius/…`, ссылаться путём |
| **ИИ: картинка → 3D** | уникальные модели под ролик | `vg.py ai3d` (§7) |

**Не смешивайте стили в одном кадре**: сканы Poly Haven (реализм) и low-poly Kenney/Quaternius рядом выглядят как коллаж. Один ролик — одна «вселенная».

## 6. Свои 3D-объекты проекта

Файл `projects/<id>/three/<имя>.js`, подключается `modules: [<имя>.js]`. Каждая экспортированная функция — объект:

```js
import { THREE, mat, mesh, blob } from "/engine/hud/three/kit.js";

// P — параметры из YAML (на момент появления), W — мир (W.heightAt(x, z), W.waveAt(x, z, t), W.scene…)
export function crate(P, W) {
  const s = P.size ?? 1;
  const g = new THREE.Group();
  const m = mesh(new THREE.BoxGeometry(s, s, s), mat(P.color ?? "#a0743f"));
  m.position.y = s / 2;
  g.add(m, blob(s * 0.8));
  g.userData.anchors = { top: [0, s, 0] };              // точки для выносок
  g.userData.update = (t, Q) => { m.rotation.y = t * (Q.spin ?? 0); };   // Q — текущие значения дорожек
  return g;
}
```

Объект, пригодившийся второму ролику, переезжает в библиотеку `props.js`.

## 7. ИИ: модель из картинки или описания (бесплатно)

```bash
python3 vg.py ai3d bus --prompt "an old rusty abandoned city bus, three-quarter view"   # FLUX.1-schnell → картинка → Hunyuan3D-2 → GLB
python3 vg.py ai3d statue --image projects/<id>/refs/statue.png                         # своя картинка → GLB
```

Результат — `assets3d/ai/<имя>.glb` (с текстурой), в сцене `{prop: model, src: "ai/<имя>.glb", height: 3}`. Работает через бесплатные Hugging Face Spaces (ZeroGPU). **Без токена квота — секунды в день на общий IP** (в облачной сессии её обычно уже выбрали соседи); с бесплатным токеном Hugging Face (`HF_TOKEN` в переменных окружения, права «read») хватает на несколько моделей в день. Локально (без видеокарты) такие нейросети слишком медленные.

## 8. Правила качества (как для всех роликов)

- **Вёрстка 2D поверх 3D** — по `docs/DRAW.md` §10.1: заголовки в верхней трети, поля ≥ 28 px; главный 3D-объект ставьте камерой так, чтобы он не попадал под заголовок и субтитры (`look` выше/ниже — объект сдвигается в кадре).
- **Вертикальный кадр узкий**: при `fov: 40` по ширине видно лишь ≈ ±13° от оси взгляда. Несколько объектов разводите **по глубине** (дальше — меньше), а не по сторонам — иначе они уйдут за край. Выноски указывают на `w.<id>.top` и обязаны попадать на видимый объект.
- **Ничего не висит**: ставьте объекты `ground: true` и утапливайте основание (`pos[1]` ≈ −0.2…−0.3); разброс — после рельефа.
- **Глубина и воздух**: 3+ плана (передний — объект, средний — вода/остров, дальний — горы/облака), дымка `fog` в цвет горизонта делает даль светлее — так же, как в живописи. Один источник света (солнце) на весь шот.
- Смотрите начало, середину и конец каждого шота (`vg.py preview <id> --at …`, быстрее — `vg.py draw <id> --frames 100,230 --force` и смотреть `build/<id>/drawn/`) до полного рендера.
- **Готовые модели проверяйте на габариты**: `height` масштабирует по рамке модели целиком. Лежачий ствол с `height: 5` станет бревном на 30 м поперёк улицы; у противогаза Poly Haven к маске приделан шланг на метр — при `height` маска сжимается до 3 см. Для таких моделей — `size: 1` (натуральный размер) и поворот `rot`. Движок пишет в лог `[page] … предупреждение`, если модель после `height` стала шире своей высоты в 4 раза.
- **Не подносите камеру вплотную к случайным объектам**: голова фонаря в 1 м над камерой читается как непонятное пятно. Перед рендером проверьте, что в кадре нет «обрезков» декора у края.
- **Видимое небо — по настроению ролика**: HDRI отлично светит, но фото-небо может быть «не того» цвета (голубое для постапокалипсиса). Тогда `backdrop: false` + свой градиент `zenith/horizon` и дымка `fog_color` в тон.
- **Что падает — падает с того, что видно**: `collapse` ставится на верхний край стены, которая в кадре, — иначе куски летят из пустого неба.

## 9. Скорость

Один поток SwiftShader: low-poly сцена ≈ 3–6 с/кадр, сцена с PBR-текстурами, GTAO и тенями 4096 ≈ 5–8 с/кадр (+ ~30 с на загрузку ассетов в начале шота). Ролик 25 с (760 кадров) в 3 потока — около 40 минут. Дешевле всего экономить на `shadow.map` (2048 вместо 4096) и `post.dof` (рисует сцену второй раз).
